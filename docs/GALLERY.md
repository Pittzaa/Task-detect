# แกลเลอรีภาพหน้าจอ

ภาพทั้งหมดแคปจากแอปที่รันจริง (production build บนเครื่องผู้พัฒนา) ด้วยข้อมูลสมมติทั้งหมด: องค์กร “สยามดีไซน์ จำกัด (ตัวอย่าง)” และชื่อคนที่ไม่มีอยู่จริง
หน้าจอเป็นภาษาไทย (กดปุ่ม EN เพื่อสลับเป็นอังกฤษ) หน้าต่างคอมพิวเตอร์กว้าง 1280 × 800 px ทุกภาพ ส่วนมือถือกว้าง 390 px (หน้าไม่ล้นจอด้านข้างทุกหน้า)
ระบบมีองค์กรเดียว คนแรกที่ได้รับเชิญ (ในตัวอย่างคือ “สมชาย ใจดี”) เป็นผู้ดูแลสูงสุด จึงเห็นปุ่มลบและหน้าตั้งค่า → ทั่วไป ที่คนอื่นไม่เห็น

ภาพที่ใช้ในหน้าแรกของ [README](../README.md) เป็นชุดย่อของหน้านี้ รูปทั้งหมดใส่เป็นรูปธรรมดาทีละรูป (ไม่ใช้ตาราง HTML) เพื่อให้แสดงได้ทุกที่ที่อ่านไฟล์ Markdown

## อีเมล (HTML ทุกฉบับ)

อีเมลทุกฉบับที่ระบบส่งเป็น **HTML** (มีข้อความธรรมดาแนบเป็นคู่ฉบับ) ภาพด้านล่างสร้างจากแม่แบบจริงในโค้ดด้วยข้อมูลสมมติ

### อีเมลเตือนงานค้างรายวัน

ส่งให้แต่ละคน **วันละฉบับเดียว** รวมงานที่ตนรับผิดชอบ ซึ่งยังไม่เสร็จ และเลยกำหนดแล้วหรือครบกำหนดวันนี้/พรุ่งนี้ (แสดงสูงสุด 30 งาน ที่เหลือบอกจำนวน) บอกโปรเจกต์ สถานะ ความสำคัญ และวันกำหนด ใครไม่มีงานค้างจะไม่ได้รับอีเมล

![อีเมลเตือนงานค้าง](gallery/34-email-deadline.png)

### อีเมลแจ้งเตือน

เช่น ถูกมอบหมายงาน (ชื่องานถูกครอบด้วยการ escape เสมอ ใส่โค้ด HTML ในชื่องานก็ไม่ทำให้อีเมลแสดงผลผิด)

![อีเมลแจ้งเตือน](gallery/35-email-notification.png)

### อีเมลตั้งรหัสผ่านใหม่

ขอได้ครั้งเดียวต่อ 2 ชั่วโมงต่อที่อยู่อีเมล และลิงก์ใช้ได้ 2 ชั่วโมง

![อีเมลตั้งรหัสผ่านใหม่](gallery/36-email-reset.png)
